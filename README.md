# User Management System

A simple PHP-based user management system with CRUD functionality.

![Screenshot](screenshot.png) *(Optional: Add screenshot later)*

## Features

- User registration
- User authentication
- Role management (Admin, Author, Guest)
- Password hashing
- Responsive interface

## Requirements

- PHP 7.4+
- MySQL 5.7+
- Apache/Nginx web server
